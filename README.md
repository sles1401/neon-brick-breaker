# Neon Brick Breaker

Game arcade HTML5 ringan dan seru untuk mengisi waktu luang! Dibuat dengan HTML5 Canvas dan Tailwind CSS dalam satu file (`index.html`).

## Cara Main
1. Buka `index.html` langsung di browser (atau aktifkan **GitHub Pages** di repo ini).
2. Klik **Mulai Main** (atau tekan **Spasi**).
3. Gerakkan papan menggunakan **mouse**, **sentuhan layar**, tombol **← →**, atau **A / D**.
4. Pantulkan bola untuk menghancurkan semua balok dan tangkap power-up yang jatuh:
   - ⚡ **Lebar** — papan lebih panjang sementara
   - 🔥 **Api** — bola menembus balok tanpa memantul
   - ✨ **x3** — multi-bola
   - ❤️ **+1** — tambah nyawa
